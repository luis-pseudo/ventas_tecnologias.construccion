# Contribución del Integrante 1: Infraestructura y Base de Datos

## Tareas realizadas:
- Configuración del servicio **PostgreSQL 16** mediante `docker-compose.yml`.
- Diseño y estructuración del script SQL DDL (`scripts/db/01-schema.sql`) para las entidades de productos, ventas y detalles de venta.
- Pruebas locales de levantamiento de contenedor y persistencia de volúmenes en Docker.

## Instrucciones de ejecución:
Para levantar la base de datos:
\`\`\`bash
docker compose up -d
